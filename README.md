# paper-LLM-SFOA-Entity-Aware-LSTM-for-Solar-Forecasting
A hybrid solar energy forecasting framework integrating Large Language Models (LLMs), the Swordfish Movement Optimization Algorithm (SFOA), and Entity-Aware LSTM. LLMs support data preprocessing, SFOA optimizes features and parameters, and Entity-Aware LSTM captures temporal patterns to improve forecasting accuracy and robustness
